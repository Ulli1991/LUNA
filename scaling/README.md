# scaling/ — viper GPU-scaling scratch tree

Viper-specific harnesses + run outputs (hardcoded /viper paths; the directory
is gitignored except this README). Shipped results live in code_paper_figs/ +
figures/*.csv, regenerated by scripts/validation/plots/scaling_plot_fp64.py.

## Harness
- `launch.sh {point|weak|strong}` — generate + sbatch one Sedov-3D scaling
  point (drives scripts/validation/runs/sedov3d_run.py; env: STEPS, PART, X64,
  WALL, LUNA_HYDRO_FUSED). `collect.sh` parses the LAST "perf = X Mcells/s"
  line per run (steady-state; ignore the compile-tainted average). `jobs.txt`
  is the submission log.
- `hydro_audit.py`, `fig3_bench.py`, `halo_stress.py` — kernel/step benches.
- `mg_verify.py`, `fmg_verify.py`, `mass_unit_test.py` — correctness probes
  (candidates for promotion into tests/).

## Run-name key
`runs/<tag>_g<G>_<N>[b]` = G GPUs, N^3 grid (b = 32^3 blocks); `dbg*` debug,
`sat*` saturated-tile ladder, `def*/fused*` = default vs LUNA_HYDRO_FUSED=1
kernel. `stress/z*_g<G>_*` = z-axis/mesh-shape halo stress runs (zyx = 3-axis
split). `amr_scale/` = AMR ladder (`snap_g8dgat` = 8-GPU dense-gather snap,
`snap_g8ifc` = iface reflux); `amr_mp/loopA/B/C` = the multi-process A/B/C
bit-parity gates; `amr_hero/` = adiabatic hero runs; `movies/` = talk-movie
sbatches; `repro/` = one-off bug repros (ovf_* overflow, dt_* timestep,
zel_probe*.py = the 2026-07-28 Zel'dovich integrator/mass-leak dissection).
